Y2R STORE COMPACT LANDING

النسخة دي صفحة واحدة مختصرة:
- 4 منتجات في نفس الشاشة/الصفحة.
- كل منتج له صورته وHook وسعره وزر طلب.
- فورم واحد فقط أسفل المنتجات.
- عند الضغط على منتج، يتم تحديده تلقائياً داخل الفورم.
- Google Sheets يسجل المنتج والسعر وبيانات العميل وUTM.
- عداد 8 ساعات يتجدد تلقائياً.

Google Sheets:
1) افتح Google Sheet.
2) Extensions > Apps Script.
3) الصق google-apps-script.gs.
4) Deploy > New deployment > Web app.
5) Execute as: Me.
6) Who has access: Anyone.
7) انسخ Web App URL.
8) افتح index.html واستبدل YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL بالرابط.

رفع مجاني:
GitHub Pages -> Public Repository -> ارفع index.html والصور الأربع -> Settings > Pages -> Deploy from main/root.
